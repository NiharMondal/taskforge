# @taskforge/web

The Taskforge frontend: Next.js 16 (App Router), React 19, HeroUI v3, React Query and Auth.js.

Run it from the repo root. It needs the backend running too:

```bash
pnpm dev:web      # http://localhost:3000
pnpm typecheck    # this app has no test runner
```
